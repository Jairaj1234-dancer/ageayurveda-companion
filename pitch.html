How it actually works

A grounding pipeline, not a chat wrapper.

Every claim the model makes resolves to a citable verse. Tools fire only when wellness intent is detected. Tenants bring their own Anthropic key — we don't carry inference cost.

Why the architecture matters

Each layer locks in switching cost.

The corpus is owned. The retrieval is tuned. The tool defines commerce. The system prompt defines tone. A competitor would need to reproduce all four — without the heritage that vouches for any of it.

  • Corpus moat. A Sanskrit scholar at Baidyanath can produce 100 verses in a week. A YC startup cannot, at any price.
  • Tenant model. BYO Anthropic key — clients pay their own inference. We sell the layer above it.
  • Source allowlists. A Patanjali tenant can pin to Charaka. A Himalaya tenant to Aṣṭāṅga Hṛdaya. Same engine, different surface.
  • Audit endpoint. Every assistant message records exactly which verses grounded it. Nothing else has that.
  • Per-tenant rate & cost. Each tenant has its own per-minute cap and a daily-aggregate spend dashboard.
  • Multilingual by default. A user typing in Devanagari gets the same retrieval quality as English.
